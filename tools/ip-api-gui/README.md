# 多出口 IP 更换工具（本地图形界面）

在自己电脑上用的小程序，调用面板的[换 IP API](../../docs/API.md)：列出实例的多出口 IP、换选中的那一个、
一键换全部、看进度和结果。只用 Python 标准库，不用装任何第三方包。

## 打开

- **Windows**：双击 `启动.bat`。没装 Python 的话先装 [Python 3](https://www.python.org/downloads/)
  （安装时勾选「Add python.exe to PATH」）。
- **Linux / macOS**：`python3 ip_api_gui.py`（Linux 上可能要先装 `python3-tk`）。

## 第一次用

1. 面板 →「设置」→「API 密钥」→ 新建一个密钥并复制。
2. 面板实例详情 →「保留 IP」→「多出口 IP」→ 展开「用 API 换 IP」，复制 `BASE="…"` 那一行。
3. 打开工具，把 BASE 整行粘贴到「BASE 地址」，密钥粘贴到「API 密钥」。
   需要的话勾「记住密钥」，点「保存设置」。
4. 点「刷新列表」。

## 用法

- **更换选中的**：在列表里选中一行，点「更换选中的」。没有公网 IP 的那行会直接分配一个。
- **一键换全部**：换这台实例全部辅助 IP 的公网 IP。
- 换的过程中工具每 2 秒查一次进度，下面的表里显示每个私网 IP 的「旧公网 IP → 新公网 IP」；
  换完会自动刷新上面的列表。「复制新地址」把换好的「私网 IP ⇥ 新公网 IP」复制到剪贴板。
- 关掉工具不影响正在进行的更换（它在面板后台跑），重新打开后点「查看最近一次」就能接着看。

## 设置保存在哪

- Windows：`%APPDATA%\ip-api-gui\config.json`。勾了「记住密钥」时，密钥用 Windows 自带的 DPAPI 加密，
  只有当前 Windows 用户能解开，拷到别的电脑上也用不了。
- Linux / macOS：`~/.config/ip-api-gui/config.json`（权限 600），勾了「记住密钥」时密钥是**明文**保存的。

不勾「记住密钥」就只保存 BASE 地址，每次打开要重新粘贴密钥。

## 注意

- 面板用 `http://IP:8000` 直连时，密钥是明文经过网络的，工具会在 BASE 地址下面提示；建议面板改用域名 + HTTPS。
- 旧公网 IP 删除后无法找回；换的过程中对应的出口会断开，直到新 IP 绑好。
